# Virtualization

**Virtualization** is a framework or methodology of **dividing the resources of a computer into multiple execution environments**, by applying one or more concepts or technologies such as hardware and software partitioning, time-sharing, partial or complete machine simulation, emulation, quality of service, and many others.

Virtualization is the **creation of a virtual (rather than actual) version of something**, such as an operating system, a server, a storage device or network resources.

The principle of virtualization is a principle of **sharing**.

To be effective, virtualization must respect the following principles:

- **Isolation**: each OS must be independent and cannot interfere with the others.
- **Transparency**: the execution of applications and services is identical to that on a physical system.

---

## Key Points

1. **Abstraction** of computing resources.
2. **Distribution** of resources through different tools, so that they can be used by several virtual environments at a same time.
3. Creation of **virtual environments**.

---

## Abstraction

Virtualization is a process that will allow to:

- Hide the physical characteristics of an IT resource in a way that simplifies interactions between that resource and other systems, other applications, and users.
- Perceive a physical resource as several logical resources.
- Perceive several physical resources as a single logical resource.
