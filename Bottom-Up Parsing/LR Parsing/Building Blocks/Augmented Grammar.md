# Augmented Grammar

An **augmented grammar** is a [[Formal Grammar|grammar]] [[Formal Language Theory/Building Blocks/Derivation|derived]] from the original grammar by adding a new [[Start Symbol|start symbol]] and a single [[Production Rule|production rule]] from this new start symbol to the original start symbol.

The augmented grammar is used in LR parser construction to provide a unique starting point and signal when parsing is complete. It helps the parser know when to accept the input.
