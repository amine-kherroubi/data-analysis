# Virtualization Theorem Two

A conventional third generation computer is **recursively virtualizable** if it is virtualizable, and a [[Hypervisor|hypervisor]] can be constructed for it.

This theorem concerns the possibility of doing recursive virtualization, that is to say running one or more [[Virtual Machine|virtual machines]] within a virtual machine. This theorem states that this process is feasible as long as the hardware architecture meets the [[Virtualization Theorem One|first theorem]] and a hypervisor can be developed for this architecture.
