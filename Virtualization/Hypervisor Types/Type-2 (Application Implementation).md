# Type-2 (Application Implementation)

**Type-2 hypervisors** run on standard OSes but provide [[Virtual Machine|virtual machine]] management features to guest OSes. Examples include **VMware Workstation** and **Oracle VirtualBox**. They are software that run inside another OS. A guest OS will therefore run on a third level above the hardware.

Type-2 [[Hypervisor|hypervisors]] use [[Full Virtualization|full virtualization]]. Since guest OSes are not aware of being virtualized, they do not need to be adapted.
