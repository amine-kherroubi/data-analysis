**Hardware virtualization (HV)** is a virtualization approach that aims to improve the performance of [[Virtual Machine|virtual environments]] by using the hardware capabilities of the physical components of the machine, especially the processor. It ensures optimal performance but requires a virtual or physical machine for complete management of the virtual environment (e.g. **vSphere Client** from VMware).

The hardware virtualization method consists of directly installing on the hardware a minimal software layer (bare-metal) allowing the creation and configuration of virtual machines.

HV is supported by [[Type-1 (System Implementation)|type-1]] and [[Type-0 (Firmware Implementation)|type-o]] hypervisors.
